## Engineering & Research Principles

> **Correctness. Reproducibility. Performance. Clarity.**

- **Build for a purpose:** Every implementation should address a meaningful computational, analytical, or engineering problem.
- **Verify results:** Use appropriate tests, numerical checks, comparisons, and evaluation metrics.
- **Write maintainable software:** Favor clear architecture, modular components, and readable code.
- **Make work reproducible:** Document dependencies, execution procedures, assumptions, and data sources.
- **Measure performance:** Evaluate efficiency, correctness, and computational tradeoffs where relevant.
- **Communicate clearly:** Explain technical findings, limitations, and practical implications.
