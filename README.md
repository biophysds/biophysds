## Development Philosophy

> Clean code. Reproducible workflows. Meaningful results.

- **Correctness:** Implement solutions that can be tested and independently verified.
- **Reproducibility:** Document dependencies, data sources, execution steps, and experimental conditions.
- **Software quality:** Use modular design, appropriate language features, automated tests, and clear documentation.
- **Analytical rigor:** Evaluate models using meaningful baselines, metrics, and validation procedures.
- **Performance:** Consider computational efficiency, scalability, and resource requirements.
- **Communication:** Translate technical results into understandable visualizations, reports, and documentation.
- **Practical relevance:** Design projects around meaningful problems and professional engineering workflows.
